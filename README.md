# Professional C++ (6th Edition) – Exercise Repository

This repository contains my solutions and personal notes for the exercises from the book **Professional C++ (6th Edition)** by Marc Gregoire.

## 📘 About the Book

*Professional C++* is a comprehensive guide that covers modern C++ programming techniques, best practices, and the Standard Template Library (STL). It’s designed for intermediate to advanced developers looking to deepen their understanding of C++.

## 📂 Repository Structure

The repository is organized by chapters for easier navigation. Each chapter contains:

- 📄 Source code (`.cpp`, `.h`)
- 📝 Exercise-specific notes or explanations
- ✅ My attempts at solving each problem

## 🧰 Tools & Environment

- **Compiler**: GCC / Clang 
- **C++ Standard**: C++23
- **Build System**: Make / VS-code
